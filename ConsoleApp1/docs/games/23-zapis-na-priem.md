# Запись на приём

## Бизнес-задача

Вы создаёте систему записи на приём — в поликлинику, парикмахерскую или автосервис. Нужно показывать свободные слоты, записывать клиентов и отменять записи.

## Цель обучения

- Классы `TimeSlot`, `Appointment`, `Client`
- Массив слотов на день, LINQ: `slots.Where(s => s.IsFree)`
- Enum `SlotStatus` (Free, Booked)
- Валидация: нельзя записать на занятое время

## Требования

1. Расписание на один день: слоты с **9:00 до 18:00**, каждый слот — **30 минут** (всего 18 слотов).
2. Программа должна позволять:
   - Показать расписание (время + статус + имя клиента)
   - Показать только **свободные** слоты
   - Записать клиента (имя, телефон, выбор слота)
   - Отменить запись (освободить слот)
   - Найти запись по имени клиента
3. Нельзя записать двух клиентов на одно время.
4. При отмене слот снова становится свободным.
5. При записи выводить подтверждение: «Иванов записан на 14:00».

## Пример работы

```
Расписание на сегодня:
09:00  [свободно]
09:30  [свободно]
10:00  [занято] Петров, 89161234567
10:30  [свободно]
...

1. Показать расписание
2. Свободные слоты
3. Записать клиента
4. Отменить запись
5. Найти по имени

> 3
Имя клиента: Сидорова
Телефон: 89001112233
Выберите время (например 14:00): 14:00
Сидорова записана на 14:00
```

## Рекомендуемые классы

```
TimeSlot       — Time, Status, Client (nullable)
Client         — Name, Phone
AppointmentBook — массив TimeSlot, Book(), Cancel(), FindFree()
AppointmentApp  — меню, игровой цикл
```
