# Домино (упрощённое)

## Цель обучения

- Класс `DominoTile` с двумя значениями (Left, Right)
- Массив/список костяшек в руке игрока и на столе
- LINQ: `hand.Where(t => t.CanConnect(chainEnd))`
- Random для раздачи

## Правила

Упрощённая версия без полноценной партии на 4 игрока.

1. Костяшки домино: пары чисел от **0 до 6** (как в стандартном наборе, 28 штук).
2. Каждому игроку раздаётся по **7 костяшек**, остальные в «базаре».
3. Первый ход — любая костяшка на стол.
4. Далее игроки по очереди кладут костяшку, у которой **одно число совпадает** с концом цепочки на столе.
5. Если подходящей костяшки нет — взять одну из базара (`Random` или по порядку).
6. **Победа** — первый, кто выложил все костяшки.
7. Если базар пуст и ходить нельзя — пропуск хода.

## Пример работы

```
Стол:  [3|5] - [5|1] - [1|6]
Рука:  [2|4] [0|3] [6|6] [1|1]
Конец цепочки: 6
Ваш ход — введите индекс костяшки: 
```

## Рекомендуемые классы

```

DominoDeck     — массив 28 костяшек, Shuffle, Draw

```
