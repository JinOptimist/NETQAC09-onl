# Викторина

## Цель обучения

- Массив объектов `Question`
- LINQ: `questions.Where(q => q.Topic == "C#")`, `results.Sum(r => r.Score)`
- Классы `Question`, `Answer`, `QuizSession`
- Enum `Difficulty` (Easy, Medium, Hard)

## Правила

1. Викторина содержит **10–20 вопросов** из массива (зашиты в код или загружены из файла).
2. Каждый вопрос имеет:
   - Текст вопроса
   - 4 варианта ответа (A, B, C, D)
   - Номер правильного ответа
   - Категорию и сложность
3. Игроку показывается вопрос и варианты.
4. За правильный ответ — **+10 очков** (или +5/+10/+15 по сложности).
5. За неправильный — **0** (штраф за ошибку можно не делать).
6. В конце — итоговый балл и оценка:
   - 0–40: Новичок
   - 41–80: Знаток
   - 81+: Эксперт

## Пример работы

```
Какой тип используется для целых чисел в C#?
A) float
B) int
C) string
D) bool
Ваш ответ: B
Верно! +10 очков

Итого: 70 очков из 100. Оценка: Знаток
```

## Рекомендуемые классы

```
Question       — текст, варианты[], правильный индекс, Topic, Difficulty
QuizSession    — текущий вопрос, счёт, список результатов
QuizGame       — выбор категории, игровой цикл
```
