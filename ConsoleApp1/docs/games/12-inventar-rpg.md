# Инвентарь RPG

## Цель обучения

- Наследование предметов: `BaseItem` → `Weapon`, `Potion`, `Armor`
- Списки и массивы предметов
- LINQ: `inventory.Where(i => i is Potion)`, `inventory.First(i => i.Name == "...")`
- Enum `ItemType`, `EquipSlot`

## Правила

Ваша задача — реализовать **меню управления инвентарём** героя в стиле RPG (без сложной боевой системы).

1. У героя есть:
   - **Инвентарь** (до 20 предметов)
   - **Экипировка**: оружие, броня, аксессуар
   - **Здоровье** (0–100)
   - **Атака** и **Защита** (базовые + бонусы от предметов)
2. Меню действий:
   - Показать инвентарь
   - Экипировать предмет
   - Использовать зелье (восстанавливает HP)
   - Выбросить предмет
   - «Сразиться с монстром» (упрощённо: если Attack > монстр.HP — победа, иначе урон герою)
3. Стартовый набор: меч (+5 атаки), зелье (+30 HP), кожаная броня (+3 защиты).
4. После победы над монстром — случайный предмет добавляется в инвентарь.

## Пример работы

```
=== Герой: Рыцарь ===
HP: 70/100  Атака: 15  Защита: 8

Инвентарь:
1. [Меч] +5 атаки
2. [Зелье] восстанавливает 30 HP
3. [Кожаная броня] +3 защиты

1 — Экипировать  2 — Использовать зелье  3 — Бой с монстром

> 3
Гоблин (HP: 12). Ваша атака: 15
Гоблин повержен! Получен предмет: [Кольцо] +2 защиты
```

```
abstract BaseItem    — Name, Description

  ├── Armor          — DefenseBonus

Hero               — HP, Attack, Defense, Inventory, Equipment
InventoryManager   — Add, Remove, Equip, Use
RpgInventoryGame   — игровой цикл, меню
```
