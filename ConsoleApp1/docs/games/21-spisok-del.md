# Список дел (To-Do)

## Бизнес-задача

Вы создаёте личный список задач: добавление дел, отметка выполненных, фильтрация — как в блокноте или мобильном To-Do.

## Цель обучения

- Класс `TaskItem` с полями: название, описание, приоритет, статус
- Enum `Priority` (Low, Medium, High), `TaskStatus` (New, Done)
- Массив/список задач, LINQ: `tasks.Where(t => t.Status == TaskStatus.New)`
- Switch-меню

## Требования

1. Программа должна позволять:
   - Добавить задачу (название, описание, приоритет)
   - Показать все задачи
   - Показать только **невыполненные**
   - Показать только **выполненные**
   - Отметить задачу как выполненную (по номеру)
   - Удалить задачу
2. У каждой задачи: название, описание, приоритет (низкий / средний / высокий), статус (новая / выполнена).
3. При выводе списка показывать номер, название, приоритет и статус.
4. Нельзя отметить уже выполненную задачу повторно — вывести сообщение.

## Пример работы

```
=== Список дел ===
1. Добавить задачу
2. Показать все
3. Показать невыполненные
4. Отметить выполненной
5. Удалить
0. Выход

> 1
Название: Купить молоко
Описание: В магазине у дома
Приоритет (1-низкий, 2-средний, 3-высокий): 2
Задача добавлена!
```

## Рекомендуемые классы

```
TaskItem       — Title, Description, Priority, Status
TodoList       — список задач, Add, Complete, Remove, GetActive()
TodoApp        — меню, игровой цикл
```
