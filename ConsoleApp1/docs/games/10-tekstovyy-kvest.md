# Текстовый квест

## Цель обучения

- Наследование локаций — абстрактный базовый класс и несколько наследников (как в вашем проекте с лабиринтом)
- Абстрактный класс с методом `Enter(Player player)`
- Switch по выбору действия / направления
- Список предметов игрока, LINQ-поиск предмета

## Правила

1. Игрок начинает в стартовой локации с кратким описанием.
2. В каждой локации игрок видит:
   - Описание
   - Список доступных действий (переходы, взаимодействия)
3. Примеры локаций:
   - **Лес** — можно найти ключ
   - **Пещера** — нужен ключ для входа
   - **Сокровищница** — победа при входе
   - **Река** — нельзя пройти без лодки
4. У игрока есть **инвентарь** (массив/список строк или предметов).
5. Некоторые действия требуют предмет: `inventory.Any(i => i.Name == "Ключ")`.
6. **Победа** — достижение финальной локации.
7. **Поражение** — здоровье упало до 0 (если есть боевая локация).

## Пример работы

```
Вы в: Лес
Перед вами тропинка. На земле блестит ключ.
Инвентарь: (пусто)

1 — Поднять ключ
2 — Идти к реке
3 — Идти в пещеру

> 1
Ключ добавлен в инвентарь.

> 3
Дверь заперта. Нужен ключ.

> 1
Вы вошли в пещеру...
```
