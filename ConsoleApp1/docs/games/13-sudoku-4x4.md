# Судоку 4×4

## Цель обучения

- 2D-массив `int[,]` размером 4×4
- Валидация строк, столбцов и квадратов 2×2 простыми циклами
- LINQ: `row.Distinct().Count() == 4` для проверки уникальности
- Ввод и проверка пользовательских значений

## Правила

1. Поле **4×4**. В каждой строке, столбце и квадрате 2×2 — цифры **1, 2, 3, 4** без повторов.
2. При старте часть клеток **заполнена** (8–10 подсказок), остальные пустые (0). Генерировать судоку с нуля не нужно — достаточно 3–5 заготовленных головоломок в массиве.
3. Игрок вводит координаты и цифру (1–4).
4. После каждого хода — проверка: нет ли повторов в строке, столбце и квадрате.
5. При конфликте — сообщение об ошибке, ход не принимается.
6. **Победа** — все клетки заполнены корректно.

## Пример работы

```
  1  2  3  4
1 1  0  3  0
2 0  3  0  1
3 3  0  1  0
4 0  1  0  3
```

## Рекомендуемые классы

```
SudokuBoard    — массив 4×4, SetValue, IsValid, IsComplete()
SudokuPuzzle   — готовые головоломки (массив шаблонов)
SudokuGame     — игровой цикл
```
