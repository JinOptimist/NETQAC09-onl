# Крестики-нолики

## Цель обучения

- Двумерный массив `char[,]` или `Cell[,]`
- Enum `CellState` (Empty, X, O)
- Проверка условий победы циклами или LINQ
- Игровой цикл `while` с чередованием игроков

## Правила

1. Поле **3×3**.
2. Два игрока: **X** и **O**. X ходит первым.
3. Игроки по очереди вводят координаты клетки (строка и столбец от 0 до 2 или от 1 до 3).
4. Нельзя ходить в занятую клетку.
5. **Победа** — три своих символа в ряд (горизонталь, вертикаль или диагональ).
6. **Ничья** — все клетки заполнены, победителя нет.

## Пример работы

```
  0 1 2
0 . . .
1 . X .
2 . . O
```

## Рекомендуемые классы

```
GameBoard      — массив 3×3, метод PlaceMark, метод IsFull
GameController — цикл ходов, проверка победы
WinChecker     — статический метод или отдельный класс
```

## Проверка победы (без сложных алгоритмов)

Проверить 8 линий вручную:
- 3 горизонтали
- 3 вертикали
- 2 диагонали

Или собрать линии в массив и использовать LINQ:
```csharp
lines.Any(line => line.All(cell => cell == currentPlayer))
```
