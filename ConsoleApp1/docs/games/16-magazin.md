# Симулятор магазина

## Цель обучения

- Классы `Product`, `Cart`, `Shop`
- Массив товаров, LINQ: `products.Where(p => p.Price < 100)`, `cart.Sum(p => p.Price)`
- Switch для меню действий
- Валидация баланса при покупке

## Правила

Ваша задача — реализовать консольный магазин. Базовый режим: **покупатель**.

1. В магазине есть **каталог товаров** (массив 10–15 позиций):
   - Название, цена, количество на складе, категория
2. У игрока стартовый баланс: **1000 монет**.
3. Меню:
   - Показать все товары
   - Показать товары по категории (LINQ `Where`)
   - Купить товар (по номеру или имени)
   - Показать корзину и итоговую сумму
   - Оформить покупку (списать деньги, очистить корзину)
   - Выйти
4. Нельзя купить больше, чем есть на складе или чем позволяет баланс.
5. **Дополнительная цель** (по желанию): купить набор из 5 обязательных товаров за минимальную цену.

## Пример работы

```
Баланс: 1000 монет

1. Хлеб — 50 руб. (осталось: 20)
2. Молоко — 80 руб. (осталось: 15)
3. Яблоки — 120 руб. (осталось: 30)

> Купить товар №2
Молоко добавлено в корзину.

Корзина: Молоко (80 руб.)
Итого: 80 руб.

> Оформить покупку
Покупка завершена. Баланс: 920 руб.
```
