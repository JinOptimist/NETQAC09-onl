# Змейка

## Цель обучения

- Список/массив координат тела змейки
- Enum `Direction` (Up, Down, Left, Right)
- Игровой цикл с обновлением состояния
- LINQ: `snake.Any(segment => segment.X == food.X && segment.Y == food.Y)`

## Правила

1. Поле **15×10** (или настраиваемое).
2. Змейка — цепочка сегментов, стартовая длина **3**.
3. На поле в случайной свободной клетке появляется **еда** (`*`).
4. Игрок меняет направление (W/A/S/D или стрелки) **до** каждого хода.
5. Каждый тик: голова двигается, хвост убирается (если не съели еду).
6. Съев еду — змейка **растёт** на 1 сегмент, появляется новая еда.
7. **Поражение** при столкновении со стеной или с собственным телом.
8. **Счёт** — количество съеденной еды.
9. Для хранения тела змейки используйте `List<Point>`: добавляйте сегмент в начало, удаляйте с конца.

## Пример работы

```
###############
#             #
#  ***        #
#   @         #
#             #
###############
```

`@` — голова, `*` — тело, `#` — стена.

## Рекомендуемые классы

```
Point          — X, Y (или использовать вложенный класс)
Snake          — список сегментов, направление, Move(), Grow()
SnakeGame      — поле, еда, игровой цикл
GameRenderer   — отрисовка (Console.Clear + цикл)
```
