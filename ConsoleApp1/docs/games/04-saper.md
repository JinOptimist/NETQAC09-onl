# Сапёр (упрощённый)

## Цель обучения

- 2D-массив клеток с наследованием (абстрактный базовый класс клетки и наследники — как в проекте с лабиринтом)
- Подсчёт соседей простыми циклами (8 направлений)
- Enum `CellState` (Hidden, Revealed, Flagged, Mine)
- LINQ: `cells.Count(c => c.IsMine)` для статистики

## Правила

1. Поле **8×8** (или 9×9), на нём спрятано **10 мин**.
2. Мины расставляются случайно при старте (`Random`).
3. Игрок вводит координаты клетки для **открытия**.
4. Открытая пустая клетка показывает **число соседних мин** (0–8).
5. Открытие клетки с миной — **поражение**.
6. **Победа** — открыты все клетки без мин.

> Вам не нужно реализовывать автоматическое открытие соседних пустых клеток (flood fill). Достаточно открывать по одной клетке за ход.

## Пример работы

```
  0 1 2 3 4 5 6 7
0 # # # # # # # #
1 # 1 0 0 1 # # #
2 # # # # 1 # # #
```

`#` — закрытая клетка, цифры — число соседних мин, `*` — мина (показывается при проигрыше).

## Рекомендуемые классы

```
abstract BaseMineCell   — координаты, абстрактный символ
MineCell                — мина
EmptyCell               — пустая, свойство NeighborMineCount
Minefield               — массив клеток, генерация мин
MineSweeperGame         — игровой цикл
```
