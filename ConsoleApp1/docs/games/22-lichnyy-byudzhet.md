# Личный бюджет

## Бизнес-задача

Вы создаёте приложение для учёта личных денег: запись доходов и расходов по категориям и просмотр остатка. Аналог домашней тетради «доходы / расходы».

## Цель обучения

- Классы `Transaction`, `Category`
- Enum `TransactionType` (Income, Expense)
- LINQ: `transactions.Where(t => t.Type == Expense).Sum(t => t.Amount)`
- Массив операций, группировка по категориям

## Требования

1. Стартовый баланс: **0** (или вводится при первом запуске).
2. Программа должна позволять:
   - Добавить **доход** (сумма, категория, комментарий)
   - Добавить **расход** (сумма, категория, комментарий)
   - Показать текущий баланс
   - Показать все операции
   - Показать операции за выбранную категорию
   - Показать сумму расходов по каждой категории
3. Категории доходов: Зарплата, Подарок, Прочее.
4. Категории расходов: Еда, Транспорт, Развлечения, Прочее.
5. Сумма не может быть отрицательной или нулевой.
6. Баланс = сумма доходов − сумма расходов.

## Пример работы

```
Текущий баланс: 12 500 руб.

1. Добавить доход
2. Добавить расход
3. Показать баланс
4. История операций
5. Расходы по категориям

> 2
Сумма: 350
Категория (1-Еда, 2-Транспорт, 3-Развлечения, 4-Прочее): 1
Комментарий: Обед
Расход записан. Баланс: 12 150 руб.
```

## Рекомендуемые классы

```
Transaction    — Amount, Type, Category, Comment, Date
Budget         — список Transaction, GetBalance(), Add()
BudgetApp      — меню, игровой цикл
```
