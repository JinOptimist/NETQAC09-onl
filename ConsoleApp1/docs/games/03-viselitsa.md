# Виселица

## Цель обучения

- Работа со `string` и `char`
- Массив или список угаданных букв
- LINQ: `word.Count(c => guessedLetters.Contains(c))`
- Цикл `do-while` (как в игре «Угадай число»)

## Правила

1. Компьютер загадывает слово из заранее подготовленного массива слов.
2. Игрок видит слово с прочерками: `_ _ _ _ _` (по числу букв).
3. Игрок вводит **одну букву** за ход.
4. Если буква есть в слове — открываются все её позиции.
5. Если буквы нет — уменьшается счётчик попыток (старт: **6–8 попыток**).
6. Повторный ввод той же буквы не тратит попытку, но выводится предупреждение.
7. **Победа** — все буквы открыты.
8. **Поражение** — попытки закончились.

## Пример работы

```
Слово:  _ А _ А _ А
Осталось попыток: 4
Угаданные буквы: А, К, О
```

По желанию — ASCII-рисунок виселицы по стадиям (0–6).

## Рекомендуемые классы

```
WordBank       — массив строк со словами, метод GetRandomWord()
HangmanGame    — состояние игры, угаданные буквы, попытки
GameRenderer   — вывод состояния в консоль
```
