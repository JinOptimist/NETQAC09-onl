# Камень-ножницы-бумага: турнир

## Цель обучения

- Массив игроков, турнирная сетка
- Enum `Move` (Rock, Paper, Scissors)
- LINQ: сортировка по победам `OrderByDescending(p => p.Wins)`
- Random для ходов бота

## Правила

### Раунд

1. Два игрока одновременно выбирают: **Камень (1)**, **Ножницы (2)** или **Бумага (3)**.
2. Камень бьёт ножницы, ножницы бьют бумагу, бумага бьёт камень.
3. Одинаковый выбор — ничья, переигровка.

### Турнир

1. Участники — массив из **4 или 8 игроков** (имена вводятся или генерируются: «Бот-1», «Бот-2»…).
2. Турнир на выбывание: победитель пары проходит дальше.
3. При ничьей в паре — переигровка (до 3 ничьих — случайная победа).
4. В конце — вывод таблицы результатов и чемпиона.

## Пример работы

```
=== Турнир КНБ ===
Участники: Анна, Борис, Вика, Глеб

--- Полуфинал ---
Анна vs Борис
Анна: 2 (ножницы), Борис: 3 (бумага)
Победитель: Борис

Вика vs Глеб
Вика: 1 (камень), Глеб: 2 (ножницы)
Победитель: Вика

--- Финал ---
Борис vs Вика
Борис: 1 (камень), Вика: 1 (камень)
Ничья! Переигровка...
Борис: 3 (бумага), Вика: 1 (камень)
Победитель турнира: Борис
```

## Рекомендуемые классы

```

RoundResolver  — статический метод WhoWins(move1, move2)
Tournament     — массив пар, метод PlayRound()
TournamentGame — главный цикл
```
