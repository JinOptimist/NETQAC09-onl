# Морской бой

## Цель обучения

- Двумерный массив / сетка клеток
- Классы `Ship`, `Cell`, `Board`, `Player`
- LINQ: поиск корабля по координатам, проверка `Any()` для попаданий
- Валидация ввода и `try/catch` при некорректных координатах

## Правила

1. Игровое поле — сетка **10×10**.
2. У каждого игрока на поле размещаются корабли:
   - 1 корабль длиной 4
   - 2 корабля длиной 3
   - 3 корабля длиной 2
   - 4 корабля длиной 1
3. Корабли размещаются **горизонтально или вертикально**, не пересекаются и не касаются друг друга (для начала достаточно проверять, что они не пересекаются).
4. Игроки по очереди называют координаты выстрела (например, `A5` или `3 7`).
5. **Попадание** — клетка занята кораблом противника. При попадании игрок ходит ещё раз.
6. **Промах** — клетка пустая. Ход переходит к противнику.
7. **Потоплен** — все клетки корабля поражены. Сообщить: «Корабль потоплен!»
8. Побеждает тот, кто первым уничтожит все корабли противника.

## Пример работы

```
Ход игрока 1. Введите координаты (например B7): B7
Попадание!

  ABCDEFGHIJ
1 ~~~~~~~~~~
2 ~~~~~X~~~~
3 ~~~~~~~~~~
...

Ход игрока 2. Введите координаты: D4
Промах. Ход переходит к сопернику.

Ход игрока 1. Введите координаты: B8
Попадание! Корабль потоплен!
```

Символы: `~` — неизвестно, `X` — попадание, `O` — промах, `S` — свой корабль.

## Рекомендуемые классы

```
Board          — поле 10×10, массив Cell
Cell           — состояние: пусто / корабль / попадание / промах
Ship           — длина, список координат, IsSunk
Player         — имя, своё поле, поле противника (видимое)
GameController — игровой цикл, очередность ходов
```
