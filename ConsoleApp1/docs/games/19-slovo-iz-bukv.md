# Слово из букв

## Цель обучения

- Массив символов (набор букв)
- Работа со `string`, проверка вхождения букв
- LINQ: `availableLetters.GroupBy(...)`, поиск слов в словаре `words.Where(w => w.Length <= 7)`
- Список найденных слов

## Правила

1. Игроку выдаётся **7 случайных букв** (как в Scrabble / Word Shuffle).
2. Обязательно присутствует одна **главная буква** (подсвечивается), она должна входить в каждое слово.
3. Игрок вводит слова из этих букв (каждую букву можно использовать не больше раз, чем она дана).
4. Слово должно быть в **словаре** (массив из 50–100 слов, зашит в код).
5. Минимальная длина слова — **3 буквы**.
6. За слово начисляются очки: длина слова (или длина × 10).
7. Повторно одно и то же слово засчитать нельзя.
8. Раунд длится **10 слов** или до команды «Стоп».
9. Побеждает тот, кто набрал больше очков (в одиночной игре — побить свой рекорд).

## Пример работы

```
Буквы:  К  О  Т  А  Р  Е  Н
Главная буква: К
Введите слово: КОТ
+3 очка (слово принято)
Введите слово: КОРАН
+5 очков
```

## Рекомендуемые классы

```
LetterSet      — массив букв, главная буква, CanFormWord(word)
WordDictionary — массив допустимых слов
WordGame       — раунд, счёт, список использованных слов
```
