# Быки и коровы

## Цель обучения

- Массив цифр фиксированной длины
- Сравнение двух массивов вложенными циклами
- LINQ для проверки уникальности цифр
- Цикл угадывания (как в игре «Угадай число»)

## Правила

1. Компьютер загадывает **4-значное число** с **уникальными** цифрами (первая цифра может быть 0, число хранится как массив или строка `"0123"`).
2. Игрок вводит своё 4-значное число (тоже с уникальными цифрами).
3. Подсказка:
   - **Бык** — цифра угадана и стоит на **правильной** позиции
   - **Корова** — цифра есть в числе, но на **другой** позиции
4. Пример: загадано `4271`, ввод `1234` → 1 бык (цифра 2 на позиции 2) и 1 корова (цифра 1 есть, но не на своём месте).
5. У игрока **10 попыток**.
6. **Победа** — 4 быка (все цифры на месте).

## Пример работы

```
Загадано число. У вас 10 попыток.

Попытка 1. Ваше число: 1234
Результат: 1 бык, 1 корова

Попытка 2. Ваше число: 4271
Результат: 2 быка, 1 корова

Попытка 3. Ваше число: 4721
Результат: 4 быка. Поздравляем, вы угадали!
```

## Рекомендуемые классы

```
SecretNumber    — генерация 4 цифр, хранение
GuessEvaluator  — метод Evaluate(guess) → (bulls, cows)
BullsCowsGame   — игровой цикл
```

## Алгоритм подсчёта (простой, без рекурсии)

```
Быки: сравнить guess[i] == secret[i] для каждого i
Коровы: для каждой цифры в guess, если она есть в secret
        но guess[i] != secret[i] — корова (учесть, чтобы не считать дважды)
```
