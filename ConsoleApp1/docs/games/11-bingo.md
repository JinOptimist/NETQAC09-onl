# Бинго

## Цель обучения

- 2D-массив карточки 5×5
- Массив выпавших чисел
- LINQ: проверка линий `row.All(n => drawnNumbers.Contains(n))`
- Random для генерации карточки и розыгрыша

## Правила

1. У игрока карточка **5×5** с числами от **1 до 75** (для начала можно взять числа от 1 до 25).
2. Центральная клетка — **бесплатная** (уже отмечена).
3. Ведущий случайным образом **вытаскивает числа** из мешка (без повторов).
4. Если число есть на карточке — игрок отмечает клетку.
5. **Победа** при заполнении любой:
   - Горизонтальной линии
   - Вертикальной линии
   - Диагонали
6. Игрок в любой момент может нажать «Бинго!» — проверка всех линий.

## Пример работы

```
 B  I  N  G  O
---------------
 3 16 32 47 63
14 22  * 51 69
 9 28 41 55 71
...
Выпало: 32, 14, 9, 47
```
