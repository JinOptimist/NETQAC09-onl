# Найди пару (Memory)

## Цель обучения

- 2D-массив или одномерный массив карточек
- Enum `CardState` (Hidden, Revealed, Matched)
- Random для перемешивания
- LINQ: `cards.All(c => c.IsMatched)` для проверки победы

## Правила

1. Поле из **4×4** карточек (8 пар символов: `A A B B C C D D E E F F G G H H`).
2. Карточки перемешиваются и показываются рубашкой вверх (`#`).
3. Игрок открывает **две** карточки за ход (вводит координаты).
4. Если символы совпали — карточки остаются открытыми.
5. Если не совпали — после паузы они снова закрываются.
6. **Победа** — все пары найдены.
7. Считается **количество ходов**.

## Пример работы

```
  0 1 2 3
0 # # # #
1 # A # #
2 # A # #
3 # # # #
```

## Рекомендуемые классы

```
MemoryCard     — Symbol, State (Hidden/Revealed/Matched)
MemoryBoard    — массив карточек, Shuffle(), Flip(x,y), CheckMatch()
MemoryGame     — игровой цикл, счётчик ходов
```
