# Колесо удачи

## Цель обучения

- Массив секторов колеса
- Наследование: `BaseSector` → `PrizeSector`, `PenaltySector`, `EmptySector`
- Random для выбора сектора
- LINQ: `sectors.Sum(s => s.Value)` для статистики сессии

## Правила

1. Колесо содержит **12 секторов** с разными значениями:
   - Призы: +10, +25, +50, +100 монет
   - Штрафы: −10, −25
   - Пусто: 0
   - Джекпот: +500 (1 сектор)
2. У игрока стартовый баланс: **100 монет**.
3. Каждое вращение стоит **10 монет** (стоимость участия).
4. Игрок нажимает Enter — колесо «крутится» (случайный индекс `Random.Next(0, 12)`).
5. Выпавший сектор применяется к балансу.
6. Игра заканчивается, когда баланс < 10 (нельзя крутить) или игрок выбирает «Выйти».
7. **Цель** — набрать максимальный баланс за сессию.

## Пример работы

```
Колесо:
 [+10] [-10] [+25] [  0] [+50] [-25]
 [+100][  0] [+10] [JACK] [-10] [+25]

Баланс: 185 монет
Стоимость вращения: 10
Нажмите Enter для вращения...
Выпало: +50! Баланс: 225
```
