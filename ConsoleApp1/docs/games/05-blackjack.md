# Блэкджек (упрощённый)

## Цель обучения

- Классы `Card`, `Deck`, `Hand`, `Player`
- Массив/список карт, перемешивание (`Random`)
- LINQ: `hand.Sum(c => c.Value)` для подсчёта очков
- Switch для действий игрока

## Правила

1. Колода — **52 карты** (4 масти × 13 достоинств).
2. Цель — набрать сумму очков **ближе к 21**, чем дилер, не превысив 21.
3. Номиналы: 2–10 по номиналу, J/Q/K = 10, **Туз = 1 или 11** (для начала можно считать: 11, а если перебор — 1).
4. Игрок и дилер получают по **2 карты**. Одна карта дилера скрыта.
5. Игрок по очереди выбирает:
   - **Взять карту** (Hit)
   - **Остановиться** (Stand)
6. При сумме > 21 — **перебор**, игрок проигрывает.
7. После Stand дилер берёт карты, пока сумма < 17.
8. Сравнение рук: больше (но ≤ 21) побеждает.

## Пример работы

```
Ваши карты: [7♥] [К♠] = 17
Карты дилера: [?] [5♦]

1 — взять карту
2 — остановиться
```
