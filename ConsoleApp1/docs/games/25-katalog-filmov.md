# Каталог фильмов

## Бизнес-задача

Вы создаёте личный каталог просмотренных фильмов: добавление, оценки, поиск по жанру, список лучших. Аналог заметок на Kinopoisk или IMDb, но в консоли.

## Цель обучения

- Класс `Movie` с полями: название, год, жанр, оценка
- Enum `Genre` (Action, Comedy, Drama, SciFi, Horror, Other)
- Массив фильмов, LINQ: `movies.Where(m => m.Genre == ...)`, `movies.OrderByDescending(m => m.Rating)`
- Поиск по названию: `FirstOrDefault`

## Требования

1. Программа должна позволять:
   - Добавить фильм (название, год, жанр)
   - Поставить оценку фильму (от 1 до 10)
   - Показать все фильмы
   - Найти фильм по названию
   - Показать фильмы выбранного жанра
   - Показать **топ-5** фильмов по оценке
   - Удалить фильм из каталога
2. Оценка — целое число от 1 до 10. Фильм без оценки отображается как «не оценён».
3. Нельзя добавить два фильма с одинаковым названием.
4. При выводе топа — сортировка по убыванию оценки.

## Пример работы

```
=== Мой каталог фильмов ===
1. Добавить фильм
2. Поставить оценку
3. Все фильмы
4. Поиск по названию
5. Фильмы по жанру
6. Топ-5
7. Удалить

> 1
Название: Матрица
Год: 1999
Жанр (1-Боевик, 2-Комедия, 3-Драма, 4-Фантастика, 5-Ужасы): 4
Фильм добавлен!

> 6
Топ-5:
1. Матрица (1999) — 9/10
2. ...
```
