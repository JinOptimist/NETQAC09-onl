# Библиотека книг

## Цель обучения

- Класс `Book` с полями: название, автор, год, жанр, доступна ли
- Массив книг, LINQ: `books.Where(b => b.Author == "...")`, `books.FirstOrDefault(b => b.Title == "...")`
- Enum `Genre`
- Switch-меню для операций

## Правила

Ваша задача — реализовать консольное управление библиотекой.

1. В библиотеке **20–30 книг** (зашиты в код или загружены из файла).
2. Каждая книга: название, автор, год издания, жанр, статус (на полке / выдана).
3. Зарегистрированный читатель может:
   - Показать все книги
   - Найти по автору
   - Найти по названию
   - Найти по жанру
   - Взять книгу (если доступна)
   - Вернуть книгу
   - Показать книги на руках у читателя
4. Нельзя взять уже выданную книгу.
5. **Игровая цель**: взять 3 книги определённого жанра и вернуть их — «задание выполнено».

## Пример работы

```
=== Библиотека ===
1. «Мастер и Маргарита» — Булгаков, 1967 [доступна]
2. «Преступление и наказание» — Достоевский, 1866 [выдана]

> Найти по автору: Булгаков
1. «Мастер и Маргарита» — 1967 [доступна]

> Взять книгу №1
Книга выдана. На руках: 1 книга

> Книги на руках
- «Мастер и Маргарита»
```

## Рекомендуемые классы

```
Book           — Title, Author, Year, Genre, IsAvailable
Reader         — Name, список взятых книг
Library        — массив Book, Search, Lend, Return
LibraryGame    — меню, игровой цикл
```
