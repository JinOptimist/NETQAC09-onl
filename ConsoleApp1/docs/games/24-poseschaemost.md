# Учёт посещаемости

## Бизнес-задача

Журнал посещаемости: вы ведёте учёт того, кто пришёл на занятие, и смотрите статистику по каждому участнику группы. Аналог бумажного журнала в школе или спортивной секции.

## Цель обучения

- Классы `Student`, `Lesson`, `AttendanceRecord`
- Массив участников и массив занятий
- LINQ: `records.Where(r => r.StudentId == id)`, `records.Count(r => r.IsPresent)`
- Enum `Attendance` (Present, Absent)

## Требования

1. В группе **10–20 участников** (имя, фамилия — заданы при старте или вводятся).
2. Программа должна позволять:
   - Показать список участников
   - Начать новое занятие (сегодняшняя дата)
   - Отметить участника как **присутствовал** или **отсутствовал**
   - Завершить занятие и сохранить результаты
   - Показать статистику участника: сколько раз был / пропустил
   - Показать список отсутствующих на последнем занятии
3. На одном занятии каждый участник отмечается ровно один раз.
4. Статистика: «Петров: 8 присутствий, 2 пропуска из 10 занятий».

## Пример работы

```
Группа: Программирование C#

1. Список участников
2. Начать занятие
3. Отметить посещаемость
4. Завершить занятие
5. Статистика участника

> 2
Занятие #3 открыто (09.07.2026)

> 3
1. Иванов - отметить
2. Петров - отметить
...
Иванов: 1-присутствовал, 2-отсутствовал > 1
```

## Рекомендуемые классы

```
Student            — Id, FirstName, LastName
AttendanceRecord   — StudentId, LessonId, IsPresent
Lesson             — Id, Date, список AttendanceRecord
AttendanceJournal  — участники, занятия, Mark(), GetStats()
AttendanceApp      — меню, игровой цикл
```
